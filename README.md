# PSP 6a - Busqueda de x en la distribucion t

Programa 6 del curso PSP. Busca el valor de x para el que la integral de la
distribucion t de 0 a x da p (usa la integracion de Simpson del programa 5).

## Requisitos

- Java 17 o mas
- Maven

## Como correrlo

```bat
mvn verify
java -cp target/classes App      (las 3 pruebas)
java -cp target/classes App 2    (solo la prueba 2)
```

## Pruebas

```bat
mvn test
```
